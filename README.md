# Phish Hunter 🎯

Phish Hunter is an interactive cybersecurity awareness game designed to help users recognize phishing emails and distinguish them from legitimate messages through realistic email scenarios.

The game provides a hands-on learning experience where players analyze email content, inspect sender addresses, examine link destinations, and identify common phishing indicators before making their decisions.

## 🎮 Game Features

- **Four Difficulty Levels:** Progress through four levels, from beginner to advanced.
- **Five Email Challenges:** Analyze five carefully designed email scenarios with different characteristics.
- **Email Inspection:** Inspect sender addresses and reveal link destinations without opening external links.
- **Interactive Learning:** Receive immediate feedback and explanations after each answer.
- **Scoring System:** Earn 20 points for each correct answer, with a maximum score of 100.
- **Progress Tracking:** Complete levels at your own pace and track your progress.
- **Leaderboard:** Save and view player scores locally in the browser.

## 🎯 Learning Objectives

- Recognize common phishing techniques and warning signs.
- Identify suspicious sender addresses and lookalike domains.
- Understand how urgency and misleading messages influence users.
- Examine URLs and distinguish legitimate links from suspicious destinations.
- Avoid relying on a single indicator, such as spelling mistakes, when identifying phishing emails.
- Develop safer email-handling and cybersecurity awareness habits.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter your player name and start hunting phishing emails!

## ⚠️ Disclaimer

Phish Hunter is an educational simulation developed for cybersecurity awareness and training purposes. All email scenarios and example domains are fictional. No real phishing emails are sent, and suspicious links are not opened.

*Stay alert. Think before you click. Become a Phish Hunter!*
